01 · Visão geral

        
O que o desafio pede

        

          Um sistema de console em Java que cadastra os funcionários de uma indústria
          e executa uma sequência de operações sobre essa lista: remoção, reajuste
          salarial, agrupamento por função, filtros por data de nascimento, ordenação,
          cálculo de idade e totalizações financeiras — 12 itens ao todo, numerados no
          próprio enunciado.
        

        

          A solução separa o código em pacotes por responsabilidade (model,
          service, util, exception), valida os
          dados de entrada em vez de aceitar qualquer coisa silenciosamente, e tem 31
          testes JUnit 5 cobrindo desde a validação de domínio até a execução completa
          do programa.

03 · Dificuldades

        
Dificuldades reais encontradas

        
Nada inventado — só o que de fato travou o processo em algum momento.

        
    
          
  • 
            ☕
            
    Versão mínima do Java
    
            
    Locale.of("pt","BR") só existe a partir do Java 19+ — precisou decidir a versão alvo do projeto com isso em mente.
    
          
    • 
          
  • 
            💰
            
    Espaço não-quebrável na moeda
    
            
    Um teste de formatação de moeda falhou por causa de um espaço não-quebrável (\u00A0) que o NumberFormat do Java insere entre "R$" e o valor — só foi descoberto rodando o teste, não lendo o código.
    
          
    • 
          
  • 
            🎯
            
    Arredondamento explícito em BigDecimal
    
            
    Cálculo de dinheiro exige RoundingMode explícito em toda divisão/multiplicação de BigDecimal, senão quebra com ArithmeticException em certos valores.
    
          
    • 
          
  • 
            🔤
            
    Ordenação de nomes acentuados
    
            
    Ordenar nomes acentuados (ex: "Heloísa") corretamente exigiu Collator de pt-BR em vez de comparação simples de String.
    
          
    • 
          
  • 
            📐
            
    Tabela dinâmica no console
    
            
    Deixar a tabela do console "bonita" sem quebrar com nomes de tamanhos diferentes ou lista vazia exigiu calcular a largura de cada coluna dinamicamente, não fixa.
